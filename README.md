# CodeAlpha Internship - Task 1: Web Scraping

This project scrapes book data from https://books.toscrape.com/ and saves it to Excel.

## Objective
To extract 100 books details including Title, Price, Rating and Availability using Python web scraping.

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Pandas
- Streamlit

## Files Included
- `codeAlpha_task-1.py` - Main scraping code
- `app.py` - Streamlit app to display data
- `books.xlsx` - Final Output (100 Books)
- `requirements.txt` - Dependencies
