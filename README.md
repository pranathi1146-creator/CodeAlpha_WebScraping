# CodeAlpha_WebScraping - Task 1

This is Task 1 of CodeAlpha Python Internship - Web Scraping Project.

## 📌 Project Description
This project scrapes book data (Title, Price, Availability, Rating) from BooksToScrape website using Python.

## 🛠️ Technologies Used
- Python
- BeautifulSoup
- Requests
- CSV

## ▶️ How to Run
1. Install libraries: pip install requests beautifulsoup4
2. Run the code: python codeAlpha_task-1.py
3. Output will be saved as books.csv
